# Scout 合规与安全说明

## 1. 密钥安全

- `.env` 文件不入版本库（已加入 `.gitignore`）
- 文档中只写配置方式，不暴露真实 Key
- 演示环境默认使用 Mock LLM，无需外部 API Key
- 答辩录屏中避免展示真实 Key

## 2. 数据来源

| 来源类型 | 处理方式 | 合规状态 |
|---|---|---|
| Mock 数据 | 人工构造的示例数据，基于公开信息整理 | 安全 |
| 官方页面 | 只引用公开可访问的产品介绍页面 URL | 安全 |
| 评测文章 | 使用示例 URL 和概括性摘录 | 安全 |
| 市场调研 | 使用示例数据和趋势描述 | 安全 |
| 用户访谈 | MVP 未接入，P1 接入前做 PII 脱敏 | N/A |

## 3. 脱敏规则

写入日志、Trace、报告前必须脱敏：

- 邮箱地址：替换为 `***@example.com`
- 手机号：替换为 `138****0000`
- 姓名：替换为化名
- 未授权访谈原文：不写入任何存储

## 4. Trace 安全

- LangSmith metadata 不写 API Key
- 不写个人隐私信息
- 不写未脱敏的原始文本
- 断网时使用本地 Trace Mirror，数据不离开本地

## 5. robots/条款

- P0 Mock 数据不涉及实时网页采集
- P1 Web 采集前检查目标站点的 robots.txt 和公开访问条款
- 只采集公开可访问的产品介绍页面
- 遵守合理访问频率，不造成服务器负担

## 6. 答辩材料

- 演示视频避免展示真实 Key
- 避免展示未脱敏的个人数据
- 数据来源声明：Mock 数据基于公开信息整理，仅用于演示
